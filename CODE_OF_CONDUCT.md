# Code of conduct

Bevel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique work rather than people, and make room for
newcomers. Harassment, insults and personal attacks are not tolerated in issues, pull
requests, discussions or anywhere else the project is represented.

## Reporting

Report behaviour that breaks this code to the maintainers privately, through the contact
details on the maintainer's GitHub profile ([@hiteshbandhu](https://github.com/hiteshbandhu)).
Reports are handled in confidence. Maintainers may remove content, or warn or ban anyone,
following the enforcement guidelines of the Contributor Covenant.
