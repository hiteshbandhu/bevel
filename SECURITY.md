# Security

Bevel is a set of UI components copied into your project, so most issues are fixed by
updating the affected file. Still, if you find a vulnerability (for example an XSS path in
a component, or a problem in the registry build), please report it privately.

**Do not open a public issue.** Use GitHub's
[private vulnerability reporting](https://github.com/hiteshbandhu/bevel/security/advisories/new)
for this repository. You'll get a reply within a week. Once a fix ships, we'll credit you
in the advisory unless you'd rather not be named.
